## 🚀 Featured Project

### 👗 [Fitted](https://github.com/k4teseo/fitted)  
Fitted is a fashion-focused social platform where users can post daily outfit photos, tag brands, and share their style with friends. Built with React Native, TypeScript, and Supabase, Fitted offers a smooth mobile experience for exploring personal style through casual posting and one-on-one interaction.

**My Contributions:**  
I helped design and implement core UI components, contributed to UX decisions, and shaped the overall look and feel of the app to make the experience intuitive and expressive.
